# NRF52832 + ICM42688P 膝关节传感器

这是基于 Nordic nRF5 SDK 16.0.0 `ble_app_uart` 示例开发的 NRF52832、ICM42688P SPI 采集与 BLE NUS 通信工程。

## 当前稳定版本

- ICM42688P 加速度计和陀螺仪采样率：200 Hz
- BLE 状态发送频率：1 Hz
- 支持手机发送 `START`、`STOP` 和 `CLOSE`
- `STOP`/断开连接后关闭 IMU，降低非采样阶段功耗
- 手机接收累计步数与振动状态

稳定版本使用 Git 标签 `v0.1-tested-icm42688` 保存。后续分阶段采样、FIFO 和 BLE 低功耗改动应在独立功能分支完成。

## 工程位置

Keil MDK 工程：

`pca10040/s132/arm5_no_packs/ble_app_uart_pca10040_s132.uvprojx`

目标芯片为 nRF52832，使用 S132 SoftDevice。请将本仓库目录放在 nRF5 SDK 16.0.0 的 `examples/ble_peripheral/ble_app_uart` 位置，保持 SDK 相对路径不变。

## 推荐开发流程

```text
main                                  已测试的稳定版本
feature/phase-aware-low-power         1 Hz试验机分阶段采样版本
feature/mobile-low-power-step-warning 当前非试验机低功耗计步版本
```

不要直接在 `main` 上进行未经验证的算法修改。新功能测试通过后再合并到 `main` 并创建新的版本标签。

## `feature/phase-aware-low-power` 试验机五周期版本

该分支用于当前没有外部相位同步信号的1 Hz标准步态试验机。程序把陀螺仪识别到的一次完整正反转作为一个试验机周期：

1. 手机发送`START`后，以25 Hz开启加速度计和陀螺仪，连续识别完整周期。
2. 第1～4周期只进行25 Hz周期计数，不进行振动窗口判定，也不发送周期数据。
3. 第4周期结束后，自动切换到50 Hz，对完整的第5周期采集加速度数据并判断强振动。
4. 第5周期结束后，立即回到25 Hz，同时发送一次累计周期数和本次振动结果；随后开始下一组五周期。
5. 如果第5周期没有按预期到来，50 Hz窗口最长保持1.5秒，超时后自动回到25 Hz，防止传感器长期停留在高采样率。
6. 没有五周期结果时，只保留30秒一次的低频状态心跳；`STOP`仍会立即发送最终状态并关闭IMU。

手机接收格式保持不变：

```text
S:5,V:0
S:10,V:1
```

其中`S`是累计完整周期数，`V`仅代表每组第5周期的加速度振动结果。检测为强振动时还会发送：

```text
WARNING,V:1
```

该版本的主要传感器参数为：正常周期识别25 Hz，第5周期振动采集50 Hz，加速度计量程±8 g，陀螺仪量程±500 dps，温度传感器关闭。若五个周期时长相同，等效采样次数约为持续50 Hz方案的60%，但陀螺仪仍需在全部周期工作以保持周期计数，因此功耗不会降低到“传感器只开1/5时间”的水平。后续若接入试验机每周期一次的TTL同步脉冲，才能在第1～4周期进一步关闭陀螺仪并获得更明显的降功耗效果。

## `feature/mobile-low-power-step-warning` 当前测试分支

这一分支不依赖1 Hz试验机相位，适合当前手持走动和功耗仪测试：

- `START`后以25 Hz开启加速度计和陀螺仪，确保启动后的第一步可以被捕获；温度传感器始终关闭。
- 正常活动时使用25 Hz六轴跟踪；动态加速度达到0.20 g或角速度达到60 dps时，短时进入600 ms的50 Hz增强窗口；包括强振动在内，增强结束后都必须以25 Hz跟踪1.4秒，将50 Hz最高占空比限制为30%。
- 连续静止3秒后自动关闭陀螺仪，仅保留25 Hz低功耗加速度计；连续检测到活动80 ms后重新开启25 Hz陀螺仪跟踪。
- 加速度计在静止门控阶段使用低功耗模式，陀螺仪只在活动阶段使用低噪声模式。
- 静止和普通活动时MCU每40 ms唤醒；静止时只读取6字节加速度，普通活动时读取12字节六轴数据；增强窗口每20 ms读取一次六轴数据，处理结束立即睡眠。
- 计步只使用陀螺仪：自动选择角速度最大的轴，同一轴出现方向相反且均超过40 dps的两个运动波瓣，计为一次完整往复。
- 计步确认、正反转间隔和防重复时间均按毫秒计算，不受25/50 Hz切换影响：每个方向至少保持60 ms，正反转至少间隔100 ms，计步后有240 ms防重复时间。
- 步数累计3步或等待2秒（满足其一）即合并发送；无新步数时每5秒发送一次状态心跳。
- 加速度计只负责强振动判定，不参与计步。
- 强冲击超过1.20 g动态峰值时立即发送警告；持续强振动还会通过1秒RMS窗口判定。
- `STOP`关闭IMU并保持连接；`CLOSE`关闭IMU、断开蓝牙并进入System OFF。

### 手机命令

| 命令 | 功能 |
| --- | --- |
| `START` | 启动活动门控计步与强振动监测 |
| `RESET` | 步数清零并清除振动报警状态 |
| `STOP` | 停止监测、关闭IMU，但保持蓝牙连接 |
| `CLOSE` | 关闭IMU、断开蓝牙并进入System OFF；复位或重新上电才能再次广播 |

启动成功会返回：

```text
MONITOR,ON
```

步数累计3步或等待2秒后发送；没有新步数时每5秒发送一次：

```text
S:120,V:0
```

检测到强烈振动时立即发送：

```text
WARNING,V:1
```

`V:1`是工程阈值警告，不代表膝关节磨损的临床诊断。当前25/50 Hz自适应采样适合往复动作计数和明显冲击，但不能替代后续试验机上的高采样率磨损振动频谱分析。

### BLE低功耗参数

- 广播间隔：2 秒，广播功率 -20 dBm。
- 首选连接间隔：200–500 ms，从机延迟4，监督超时6秒；手机拒绝时继续使用手机已有参数，不再主动断开。
- 建立连接后也将连接发射功率设置为 -20 dBm。
- 步数累计3步或等待2秒后合并发送，空闲状态每5秒发送；强烈振动立即上报。

不同手机可能拒绝从机提出的连接参数。功耗测试时应同时检查手机最终接受的连接间隔和从机延迟。
